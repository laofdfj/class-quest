# CLASS QUEST 🐾

Яркое приложение для геймификации занятий в IT-академии: классы, ученики, XP, магазин призов, таблица лидеров и экран для проектора.

## Текущий этап — MVP интерфейса

Сейчас реализовано:
- создание классов и добавление учеников;
- звания на основе общего количества заработанных XP;
- начисление и списание баллов с дневным лимитом;
- настраиваемые особые начисления;
- магазин призов с ценой в XP, себестоимостью и остатками;
- подтверждение выдачи и отмена покупки с возвратом баллов;
- месячный бюджет на призы;
- рейтинги за всё время, 7 и 30 дней;
- отдельный экран рейтинга для проектора;
- экспорт и импорт резервной копии JSON;
- адаптивный розово-голубой интерфейс с котиками и мемным настроением.

## Запуск

Открой `index.html` в современном браузере или опубликуй репозиторий через GitHub Pages.

## Важно: ограничения прототипа

На текущем этапе данные хранятся только в localStorage браузера на конкретном устройстве. Это **не облачная версия** и не система реальных ученических аккаунтов. Не используй её как единственное хранилище важных данных и регулярно экспортируй JSON-резервную копию.

Следующий этап разработки:
1. Подключить Supabase (Auth + PostgreSQL + Row Level Security).
2. Сделать защищённый кабинет преподавателя.
3. Добавить ученический вход по выданному логину/PIN и доступ только к собственному профилю.
4. Синхронизировать данные между устройствами.
5. Добавить публичный режим проектора без показа приватной информации.

## Экономика по умолчанию

- Лимит положительных XP: 50 в день на ученика (можно изменить).
- Звание зависит от общего заработка XP и не снижается после покупок.
- Покупки списывают XP с текущего баланса.
- Месячный бюджет и себестоимость призов учитываются отдельно от цены в XP.

## Безопасность

До подключения авторизации и серверных политик доступа не публикуй реальные персональные данные учеников в этой версии.
