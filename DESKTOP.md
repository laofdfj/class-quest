# Class Quest для Windows

Приложение упаковывается в Windows-инсталлятор через Electron.

## Локальный запуск для разработки

```bash
npm install
npm start
```

## Сборка установщика

```bash
npm run dist:win
```

Готовый установщик появится в каталоге `release/`. GitHub Actions также собирает установщик и прикладывает его к успешному запуску workflow как артефакт.

Приложение использует тот же Supabase-проект, что и веб-версия. Поэтому вход учителя, ученические кабинеты и облачная синхронизация работают через интернет и общую базу данных. Локальный кэш остаётся на каждом компьютере; для синхронизации требуется подключение к интернету.
